# 教材のコード枠の赤枠強調

第4章以降は、原稿作成時に全体コードと構文解説の抜粋・記述例の両方へ、赤枠で示す箇所を指定する。

- 全体コードでは節の学習目標に関わる処理をまとまりごとに囲む。離れた処理には別々の枠を使う。
- 抜粋や記述例では、その場で解説する属性・式・関数などに範囲を絞る。比較例には同じ粒度の枠を使い、正誤や変更前後のラベルを維持する。
- 配布版のコードは実ファイルのパスと行番号に照合する。通常構成の記述例は正確なコード文字列で指定し、番号欄を省く。本編では通常構成を使い、研修固有の設定は補足で扱う。
- 参照用コードなど、枠を省く理由がある場合は原稿の制作メモに理由を記す。演習の動作確認図では、操作箇所と変化する表示を赤い四角で示す。

## 原稿から組版へ反映するとき

原稿の制作メタデータに、節、ファイルパス、掲載順、対象の正確なコード文字列を記す。実ファイルを掲載する場合は該当行も記す。

組版では章フォルダーの `code-highlights.json` に指定を保存する。キーは `chapter.md` のコード枠のID。コード文字列が一意なら文字列だけで指定できる。

```json
{
  "chapter-code-id": [
    "navigate('/products')",
    {"text": "useNavigate", "within": "import { Link, useNavigate }"}
  ]
}
```

同じ文字列が複数回ある場合は、`within` に一意な文脈を指定するか、実ファイルの掲載コードなら `line` に表示される行番号を指定する。連続する行をまとめて囲む場合は、`text` に改行と途中行の字下げを含めたコードを記し、`block` を `true` にする。既存の赤枠が対象と一致するときは既存の設定を使う。

赤枠は既存教材と同じ赤の実線を使い、塗りのない四角形にする。折り返した論理行も対象に含め、語句の枠は表示行ごとに分けられる。PDFは生成元から再生成し、対象コード枠をレンダリングする。枠の位置、折り返し、文字や行番号との接触、重複を確認する。改ページ後も、節、ファイルパス、掲載順、コード文字列から対象を確かめる。
