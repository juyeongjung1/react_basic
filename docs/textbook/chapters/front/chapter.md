::: {#front-introduction .heading}
[はじめに]{.s001}
:::

::: {#front-overview .paragraph}
本コースでは、React と TypeScript を使い、REST API を介してデータベースと連携する SPA（シングルページアプリケーション）を作ります。商品を検索して詳細を開き、フォームから新規登録や更新ができるところまで、画面と API の両方を実装します。
:::

::: {#front-format-title .heading}
**講義と実機演習**
:::

::: {#front-lecture .paragraph}
4日間の講義では、商品管理システムを題材に、それぞれの機能に必要なコードと処理の流れを確認します。
:::

::: {#front-practice .paragraph}
各章の実機演習では、講義で確認した内容を人事管理システムに応用します。最初はサンプルを起動して社員データの型を定義し、画面表示・画面遷移・入力処理を組み立てます。後半で API を作り、社員情報の検索・登録・更新・削除を画面から行えるようにします。
:::

:::: {#page-2 .source-page}

::: {#front-goals-title .heading}
[コースの目標]{.s001}
:::

::: {#front-goals-intro .paragraph}
本コースの修了までに、演習手順とひな形を使って、以下の実装を行います。
:::

::: {#front-goal-react .paragraph}
■ React と TypeScript で、データを表示し、フォームの入力を処理できる。
:::

::: {#front-goal-routing .paragraph}
■ React Router で画面遷移を設定し、URL から対象データの ID を取得できる。
:::

::: {#front-goal-context .paragraph}
■ Context を使い、複数の画面で共通のデータを参照・更新できる。
:::

::: {#front-goal-api .paragraph}
■ Express とデータベースを使い、検索・登録・更新・削除の API を作成できる。
:::

::: {#front-goal-spa .paragraph}
■ REST API と React の画面をつなぎ、CRUD ができる SPA を構築できる。
:::

::: {#front-goal-option-title .heading}
**オプション実施時**
:::

::: {#front-goal-authentication .paragraph}
■ ログイン・ログアウトを実装し、利用者の状態に応じて画面と API へのアクセスを制御できる。
:::

::: {#front-course-title .heading}
[コースの進め方]{.s001}
:::

::: {#front-course-audience-title .heading}
**対象者と前提条件**
:::

::: {#front-course-audience .paragraph}
React で、画面遷移とデータベース連携のある Web アプリケーションを作りたい方が対象です。HTML と CSS で基本的なページを作成でき、JavaScript の基本文法を理解していることを前提とします。React と TypeScript の経験は問いません。
:::

::: {#front-course-plan-title .heading}
**4日間の進め方**
:::

::: {#front-course-plan .table}
| 日 | 章 | 学習内容 |
| --- | --- | --- |
| 1日目 | 第1・2章 | 開発環境と型定義、画面表示、入力処理 |
| 2日目 | 第3・4章 | 画面遷移、登録・編集フォーム、データ共有 |
| 3日目 | 第5章 | REST API と DB の接続、一覧・検索・詳細の取得 |
| 4日目 | 第6・7章 | データの登録・更新・削除 |
:::

::: {#front-course-option .paragraph}
第8章のログイン認証は、実機演習の進み具合に応じて扱います。
:::

::: {#front-course-samples-title .heading}
**配布サンプルの使い方**
:::

::: {#front-course-samples .paragraph}
各章では、その章のサンプルフォルダを開き、`package.json` がある場所で `npm install` を実行します。インストール後は、各章に記載されたコマンドで起動して演習を進めます。
:::
